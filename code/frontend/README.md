# Data Scraping Frontend

Next.js frontend for the Data Scraping application.

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Environment Variables

Create a `.env.local` file:
```
NEXT_PUBLIC_API_URL=http://localhost:3001
```

## Features

- Select B2B or B2C lead types
- Get random contacts from the selected type
- Store contact records for users
- View stored records history
